<p style="font-style: italic; color: black; font-size: 1.5em; margin-top: 25px;">Инструкция по использованию приложения для подписи чеков</p>

<p style="font-style: italic; color: black; font-size: 1.2em; margin-top: 30px;">Данное приложение предназначено для подписи чеков, чтобы в системе ваши чеки были подписаны следующим образом: <strong>логин личного кабинета + наименование устройства</strong>.</p>

<hr style="margin: 40px 0 30px 0; border: none; border-top: 2px solid #e0e0e0;">

<h3 style="color: black; font-size: 1.5em; margin-top: 30px;">Пошаговая инструкция</h3>

<p style="color: black; font-size: 1.15em;"><strong>1.</strong> Скачиваем APK-приложения, который вам отправит администратор.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/1.png" alt="Шаг 1" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>2.</strong> Устанавливаем приложение на устройство.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/2.png" alt="Шаг 2" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>3.</strong> После этого переходим в настройки телефона, ищем «Специальные возможности», там будет Screen Data — тумблер будет отключён, его нужно включить. Если будет уведомление «Доступ для приложения запрещён» — переходим к следующим настройкам.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/3.png" alt="Шаг 3.1" style="display: block; margin: 0 auto 12px auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <img src="images/4.png" alt="Шаг 3.2" style="display: block; margin: 0 auto 12px auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <img src="images/5.png" alt="Шаг 3.3" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>4.</strong> Переходим на главное меню телефона, находим приложение, зажимаем на него и нажимаем «О приложении».</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/6.png" alt="Шаг 4" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>5.</strong> В правом верхнем углу нажимаем на три точки и нажимаем кнопку «Разрешить доступ к настройкам».</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/7.png" alt="Шаг 5" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>6.</strong> Тут же в настройках приложения спускаемся ниже и находим пункт «Поверх других приложений» — нажимаем «Разрешить».</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/8.png" alt="Шаг 6" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>7.</strong> После этого возвращаемся в пункт 3 — включение спец. возможностей через настройки телефона. После того как мы включим Screen Data, заходим в само приложение.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/9.png" alt="Шаг 7.1" style="display: block; margin: 0 auto 12px auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <img src="images/10.png" alt="Шаг 7.2" style="display: block; margin: 0 auto 12px auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <img src="images/11.png" alt="Шаг 7.3" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>8.</strong> Когда мы зашли в приложение, у вас выйдет уведомление «Начать запись или трансляцию через приложение» — вы выбираете пункт «Весь экран», после нажимаете кнопку «Начать».</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/12.png" alt="Шаг 8.1" style="display: block; margin: 0 auto 12px auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
  <img src="images/13.png" alt="Шаг 8.2" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>9.</strong> У вас появляются две кнопки на экране — одна зелёная, другая красная:</p>
<ul style="color: black; font-size: 1.15em; padding-left: 20px;">
  <li><strong>Зелёная кнопка</strong> — отвечает за скриншот и отправку на сервер, а также сохраняет скриншот в галерею.</li>
  <li><strong>Красная кнопка</strong> — отвечает за прекращение работы приложения.</li>
</ul>

<p style="color: black; font-size: 1.15em;"><strong>10.</strong> После всей этой настройки можем переходить к работе по выплатам.</p>

<p style="color: black; font-size: 1.15em;"><strong>11.</strong> Заходим в приложение банка, делаем выплату.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/14.png" alt="Шаг 11" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>12.</strong> Делаем успешный скриншот транзакции, ждём, когда он отправится на сервер и сохранится в галерее.</p>
<div style="margin: 15px 0 25px 0;">
  <img src="images/15.png" alt="Шаг 12" style="display: block; margin: 0 auto; max-width: 100%; width: 320px; border: 1px solid #ddd; border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);">
</div>

<p style="color: black; font-size: 1.15em;"><strong>13.</strong> Заходим в личный кабинет по выплатам, загружаем скриншот из галереи и подтверждаем заявку.</p>
